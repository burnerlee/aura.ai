Build a high-end, futuristic social media web application named "Aura" designed for the Google AI BuilderCup. 

Core UI Components & Layout Requirements:

1. Fixed Top Navigation Bar:
   - Left: Logo icon with glowing particle ring and "Aura" title.
   - Center: Interactive Natural Language Interest Prompt pill/bar (e.g., "Cyberpunk, Machine Learning & Deep Tech") that opens a modal when clicked to edit user interest rules.
   - Right: "Create / Embed" action button and user profile avatar.

2. Interest DNA Real-Time Vector Dashboard (Desktop Sidebar):
   - A fixed right-side panel featuring a 3D animated SVG doughnut chart representing the user's live interest vector alignment percentages across multiple categories (Cyberpunk, ML, Astrophysics, Indie Pop) with a legend.

3. Responsive Masonry Content Feed:
   - A multi-column masonry grid displaying diverse card types: image/media posts, long-form articles, and cross-platform embedded posts (Substack, Twitter/X, Reddit).
   - Card Interactions: Hover effects with cinematic zoom, an "AI Insight" badge that triggers micro-explanations, and a gestural drag mechanism (dragging right to "Resonate"/boost vector weights, dragging left/holding to "Banish"/downvote with particle-glow animations feeding back into the DNA chart).

4. Natural Language Interest Prompt Modal:
   - A clean modal allowing users to type freeform natural language prompts to instantly recalibrate their feed embedding vectors.

5. Unified Omnibox Post Creator Modal:
   - A multi-tab composer modal with three modes:
     * Short-Form: Quick thoughts with category selector.
     * Long-Form: Markdown title and rich text content block.
     * Embed Link: Dedicated input for Substack, Twitter, and Reddit URLs with an automatic live preview card showing OpenGraph metadata (author, platform badge, headline) before publishing.

Make it fully interactive using modern responsive CSS (Tailwind CSS, Phosphor icons, smooth transitions, canvas particle effects for the interest adjustment gestures).

Build this as a cross-platform project. Create a responsive web interface for desktop/tablet, and add a React Native (Expo) mobile app artifact for iOS and Android that shares the same backend API and Interest DNA vector logic.
