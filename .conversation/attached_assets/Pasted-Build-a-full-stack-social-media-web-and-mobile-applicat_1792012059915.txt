Build a full-stack social media web and mobile application named "Aura" for the Google AI BuilderCup. The app centers around natural language feed personalization, multi-format content creation, and cross-platform embedding.

Core Features & Functional Modules to Implement:

1. Natural Language Interest Personalization Engine:
   - A natural language input mechanism where users type freeform descriptions of what they want to see or avoid.
   - An underlying semantic vector mapping logic that translates these text prompts into weighted category percentages (an "Interest DNA" profile).
   - Real-time adjustment mechanics where user interactions (resonation or banishing of posts) dynamically recalibrate these vector weights.

2. Omnibox Content Creator & Multi-Format Posting:
   - Short-Form Post Component: Text inputs for quick micro-thoughts or code snippets tagged to specific interest categories.
   - Long-Form Post Component: Markdown-supported rich text editor with title blocks for in-depth articles.
   - Cross-Platform Embed Engine: A URL ingestion component for Substack, Twitter/X, and Reddit that automatically parses and renders native-looking preview cards using OpenGraph or platform OEmbed metadata.

3. Adaptive Discovery Feed & Interactive Post Cards:
   - A content feed that filters posts exclusively based on the user's active natural language interest criteria and vector weights.
   - Individual Post Cards supporting image media, long-form text, and embedded external links.
   - Interactive Feedback Actions: Mechanisms for users to signal resonance or banishment, triggering live visual state changes and vector updates.
   - AI Insight Trigger: An on-demand component to generate an AI-driven explanation for why a specific post matched the user's interest criteria.

Tech Stack & Architecture:
- Responsive front-end components compatible with modern web browsers and mobile viewports.
- State management capable of handling real-time vector score shifts and dynamic feed filtering.
- Modular, clean component structure separating the feed, the interest configuration engine, and the multi-format post creator.
